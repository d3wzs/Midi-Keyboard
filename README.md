# Midi-Keyboard

<img width="830" height="617" alt="Screenshot 2026-10-25 at 12 49 36" src="https://github.com/user-attachments/assets/c296f537-49ae-433e-a047-eafd80341ff5" />

Midi Keyboard is a variation of Half Lifes Midi Keyboard (Week 3) Project. I've edited to have a better layout in my opinion. Ive added my own star design from my previous week 1 project.

The board features 3 low profile buttons, a 2 pentiometers, a rotary encoder and a Waveshare ESP32-S3-Zero as the main controller. The board has Capacitive keys aswell. 

# Features/Attributes

-Custom PCB
-Capacitive Keys
-Sliders
-Star Design
-Buttons
-Rotary Encoders
-Led lighting

# Hardware

-Waveshare ESP32-S3-Zero: Micro-controller
-PCB
-Potentiometer Bourns PTA1543: Interaction
-LED SK6812MINI-E 3.2x2.8mm Reverse Mount: Lighting
-Kailh Choc Low-Profile Switches: Interaction
-Rotary Encoder Alps EC11E H20mm: Interaction
